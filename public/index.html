本地运行 · 只分析 color / background-color / font-size · 不计继承与默认样式

HTML

仅允许 div / section / p / span 标签，id / class 属性和文本。

规则

等价精简仅支持合法 HTML 中至多 40 个元素、至多 10 条合法规则；计算后需确认才会替换规则。

选择器与层叠规则说明
  • 选择器支持：类型（div）、ID（#a）、类（.b）、后代（div p）、直接子代（section > p），如 #main .box > span；其他写法报错。
  • !important 声明优先于普通声明。
  • 普通声明：无层 > 有层；都有层时，后出现的层优先。
  • !important 声明：有层 > 无层；都有层时，先出现的层优先（与普通声明相反）。
  • 层顺序按层名首次出现的位置确定。
  • 同层（同重要级）：依次比较 ID 数、类数、类型数，再比较规则顺序（靠后者优先）。
  • “等价精简”会穷举原序规则子序列，并对每个候选重新计算层名首次出现顺序与层叠结果，找出使全部元素三属性胜出值（含无声明）不变的最短保留集；确认后才会替换规则。
  • “层顺序规划”（页面底部）只重排命名层先后：统计让指定元素属性的胜出值目标全部成立的层排列总数，并给出按层首次出现编号序列字典序最小的可行排列与各目标胜出规则。

层顺序规划

只调整命名层的先后（规则内容与顺序固定，无层声明仍参与层叠），寻找让下列目标全部成立的层排列。 每项目标为「元素路径 + 属性 + 期望胜出值」（勾选「无声明」表示要求该元素该属性没有任何匹配声明）， 期望值与胜出声明值按字符串精确比较。限 40 个元素、60 条规则、12 个命名层、1～8 项目标； 所有命名层均参与排列（无命名层算 1 个空排列）。本面板不改动 HTML 与规则。

添加目标后点击「计算层排列」，此处展示可行排列总数、字典序最小的可行排列与各目标的胜出规则。
